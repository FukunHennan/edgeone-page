水下机器人最难的不是单个传感器或单段代码，而是把姿态、舵机、Modbus、卡尔曼滤波和上位机界面整合成一套可现场使用的系统。本文记录基于 STM32F407 的水下机器人航向舵机控制系统的整体设计，重点说明工程结构与协作方式。仓库地址：[FukunHennan/underwater-robot-steering-control-system](https://github.com/FukunHennan/underwater-robot-steering-control-system)。

## 系统总览

系统分三层：硬件设计、下位机固件、上位机软件。硬件采用 STM32F407VET6 主控（168MHz Cortex-M4），通过 Modbus RTU 与上位机通信。下位机负责采集九轴姿态、磁力计、气压计、ADC、舵机控制；上位机使用 React Web Dashboard，通过 Web Serial API 直连串口，无需安装额外软件。

通信接口分配上：USART1 调试串口 115200，USART2 Modbus RTU 9600，USART3 与 ATK-MS901M 九轴传感器通信。所有外设引脚分配、电源域、隔离方式都记录在 Wiki 的 `pinout.md` 中，便于后续硬件迭代时直接复用。

## Modbus RTU 与 159 寄存器设计

水下机器人涉及的参数多，包括姿态、PWM、ADC、气压、磁力计、GPIO、红外、卡尔曼参数和舵机补偿。如果每个参数单独定义协议，协议表会越写越长，调试极其痛苦。

我使用 Modbus RTU 作为统一协议层，下位机作为从站（地址 0x01），把所有参数映射到 159 个寄存器（0x0000–0x00E8）。寄存器按功能分组：系统（0x0000-0x0005）、姿态（0x0010-0x001B）、PWM（0x0020-0x0029）、ADC（0x0030-0x0039）、PWM 频率（0x0040-0x0047）、气压计（0x0048-0x004D）、磁力计（0x004E-0x0055）、ADC 校准（0x0056-0x006B）、GPIO（0x006C-0x0077）、红外（0x0078-0x007F）、卡尔曼（0x0086-0x009E）、舵机补偿（0x00A0-0x00DF）、补偿启用（0x00E0-0x00E7）。

寄存器映射表是整个系统的契约：下位机和上位机都依赖它解析数据。Wiki 中的 `modbus-register-map.md` 完整记录了每个地址的功能、数据类型、单位和读写方向。任何参数变更都必须先改映射表，再改代码，再改界面。

## 九轴姿态融合与卡尔曼滤波

ATK-MS901M 通过 USART3 输出九轴数据（陀螺仪、加速度、磁力计、气压计）。原始数据噪声较大，直接用于舵机补偿会导致抖动。我在下位机实现六通道卡尔曼滤波器，参数 Q/R 可通过上位机实时调节，便于在不同水流条件下找到平衡点。

卡尔曼滤波的工程细节记录在 Wiki 的 `kalman-filter.md`，包括数学推导、参数选择、调参方法和复位命令。卡尔曼参数保存在 RAM 中，可通过 Modbus 写入；同时支持"保存到 Flash"命令，重启后保持上次校准值。

## 舵机姿态补偿

8 路舵机各通道独立补偿，公式为 `output = BASE + kRoll × roll + kPitch × pitch + kYaw × yaw`。BASE、kRoll、kPitch、kYaw 均保存在 Flash，支持通过 Modbus 单通道调整。补偿使能标志位于 0x00E0-0x00E7，可以单通道打开或关闭，便于调试阶段排除补偿干扰。

补偿算法与使用方法记录在 `servo-compensation.md`，包括如何根据水下机器人质心位置选择初始 BASE、如何在静水中标定 k 值、如何在动水中验证补偿效果。

## 上位机：浏览器直连的 React Dashboard

上位机使用 React 18 + Vite + TypeScript + TailwindCSS，通过 Web Serial API 直接读取串口，无需安装驱动或后台进程。5 个页面分别覆盖系统、传感器、舵机、外设、高级功能。

特性上做了几件事：

- **3D 姿态可视化 + 实时波形**：使用 Three.js 显示姿态，配合图表展示陀螺仪、加速度、磁力计时序；
- **舵机补偿配置**：通过 Modbus 写入 BASE 和 k 值，实时查看舵机输出；
- **ADC 校准面板**：每通道增益与偏移可调，结果保存到 Flash；
- **卡尔曼 Q/R 实时调节**：调参时不再需要重启下位机；
- **自动重连**：最多 10 次指数退避，避免短时断线直接报错；
- **Mock 模式**：URL 追加 `?mock` 可在无硬件时预览，便于教学演示。

## 工程结构与文档

项目目录按工程节点划分：`01-硬件设计/`、`02-下位机固件/`、`03-上位机软件/`、`Wiki/`。硬件设计包含原理图；下位机固件按 BSP 驱动组织，包括 ATK_MS901M、Modbus、Kalman、PWM、ADC、Calib、GPIO；上位机按页面、组件、状态管理分层。

Wiki 不是事后整理的文档，而是开发过程中同步维护的工程知识库：`system-architecture.md` 是整体架构图与流程图，`entities/` 目录下是各模块详细文档。这种"开发即文档"的方式让后续维护和教学成本显著下降。

## 待实现与演进方向

当前系统已实现姿态采集、舵机补偿、ADC 校准、红外收发等基础功能，待实现包括：

- PID 姿态闭环控制算法；
- 深度传感器与深度控制；
- ESP32 Wi-Fi 无线通信替代有线；
- 水下摄像头集成；
- 自主导航算法。

这些功能会逐步补到 Wiki 和寄存器表中，确保架构演进时协议层和文档同步更新。

## 小结

水下机器人项目是嵌入式工程的一次完整演练：从硬件设计到下位机协议，再到上位机可视化与现场调试，每一步都需要工程化思维。Modbus 寄存器表是系统的契约，卡尔曼滤波是数据可靠性的基础，浏览器直连上位机则把使用门槛降到最低。这套系统的 Wiki 和代码都可以作为类似嵌入式项目的参考起点。
