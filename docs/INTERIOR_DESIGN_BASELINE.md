# 内页视觉设计基准 · Cinematic Calm

本规范延续用户 2026-10-22 确认的多界面参考效果图（桌面首页、博客列表、博客正文、项目、关于及手机菜单）。该图是合成设计示意，不是网页截图；目标是统一**风景横幅、柔和白底、留白、清晰内容和中英文导航**，而不是复制不存在的虚构文章或项目。

## 公共规范

- 内页顶栏：覆盖在风景横幅顶部的轻玻璃质感，白色文字，保留原有搜索、主题、语言选择器与手机菜单。
- 尺寸：横幅高度约 215–330px，文章页采用约 110–210px 的低矮风景横幅；四角柔和，内容区使用浅色背景。
- 实景素材：复用仓库内新导入的四张独立静态 WebP 摄影照片（来源为 Unsplash License）。内页**静态**使用，不启动额外视频，兼顾阅读性能。
- 品牌色：暖灰白、深青绿色和柔和草绿色，少用大面积紫色或复杂动态渐变。
- 响应式：阅读正文桌面与目录分栏，手机改用可折叠目录；筛选项目在窄屏横向滚动；不出现横向页面溢出。
- 真实数据：文章、项目、分类、笔记、关于我的内容来自现有内容文件；不得把设计图中的示例文章数量、人物或卡片文字当成真实数据。

## 页面映射

| 页面 | 设计要点 | 实现位置 |
| --- | --- | --- |
| 博客列表 | 风景横幅、分类入口、即时搜索、图文列表 | `pages/[lang]/archives/index.astro`、`ArticleList.astro` |
| 文章详情 | 小型横幅、白底宽松排版、桌面目录与手机折叠目录 | `pages/[...path].astro` |
| 项目 | 风景横幅、原有类别筛选、轻薄卡片 | `tools/astro-registries.mjs` 的输出 + 设计系统样式 |
| 笔记 | 森林横幅、保留关键词搜索及分类筛选 | `source/{lang}/notes/index.md` 的原有结构 |
| 关于 | 风景横幅、现有头像和真实简介、技术方向标签 | `pages/[...path].astro` |
| 经历 | 风景横幅、现有时间轴 | `pages/[...path].astro` |
| 简历 | 不套新内页主题，保持 A4 可编辑/打印样式 | 原有 `resume` 页面 |
| 首页 | 保持独立的近满屏风景视频、少文字 | `docs/HOMEPAGE_DESIGN_BASELINE.md` |

## 代码维护

所有针对内页的新增视觉规则集中在 `astro-src/styles/interior-pages.css`，并通过 `.scenic-inner` 作用域启用。不要在旧 Stylus 主题文件里加入更多覆盖规则；避免破坏首页或 A4 简历。

本地验证：`npm ci && npm run check`。手动验收重点检查 `/zh-CN/archives/`、`/en/archives/`、`/zh-CN/projects/`、`/zh-CN/notes/`、`/zh-CN/about/`、`/zh-CN/experience/`、任意文章和简历；再检查 375px、768px 和 1440px 三种视口。

目前线上像素级效果仍需真实浏览器截图验收，GitHub Actions 构建通过只代表静态页面与代码审计通过。
