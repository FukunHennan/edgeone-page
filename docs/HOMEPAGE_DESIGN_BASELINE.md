# 首页设计基准 · Cinematic Calm

> 确认日期：2026-10-22。用户明确喜欢本次讨论中生成的自然风景 UI 效果图，实际网页应朝该图的**布局关系、视觉层次与安静气质**靠拢。本基准优先于过去的 Dashboard 首页设计。

## 用户确认的视觉方向

- **真实自然风景主导**：山湖、海岸、草甸、森林溪流；慢速静音视频轮播，照片作兜底。不要重新采用大面积纯色抽象图形。
- **电影感整屏首页**：风景近满屏，整图稍留细窄白边，轻微圆角。不要将首屏做成带明显大留白的缩小卡片。
- **顶部悬浮透明导航**：品牌、导航、搜索、简体中文/English 和主题切换覆盖风景上边缘。玻璃磨砂、浅色文字；仅在首页这样处理，其他页面仍保留清晰的标准顶栏。
- **少而轻的文字**：左侧白色欢迎语“慢一点，也很好。”以及一行柔和说明。字幕不可把风景遮满，避免冗长的介绍。
- **无大按钮、无常驻操作栏**：已确认删除欢迎语下方博客/项目 CTA，以及右下角圆点/箭头/暂停按钮条。博客、项目等仍在顶部导航。键盘辅助控件保持可用但不常驻。
- **移动端同样宁静**：纵向风景、适量渐变保护文字可读性，保留顶部语言切换和菜单，主要靠滑动切换风景。

## 尺寸及规则

| 项目 | 设计标准 |
| --- | --- |
| 页面背景 | 柔和浅灰白，首页风景与视口之间仅留约 10–20px |
| 主景 | 接近视口高度，宽屏不应出现上下大片空白 |
| 导航 | 覆盖主景顶部，72px 桌面 / 60px 手机，黑色透明玻璃质感 |
| 文字 | 左中位置，桌面约 46–78px 自适应标题，手机约 34–47px |
| 风景 | H.264 MP4 + 本地 WebP，保持静音和缓慢的 14s 切换 |
| 控件 | 不常驻出现，键盘聚焦时才可见 |
| 语言 | 顶部可见，并与目标语言页面对应 |
| 内页 | 博客、笔记、项目、经历等维持独立可读布局，不套首页风景效果 |

## 为什么之前实站看起来与效果图差很多

此前存在互相冲突的主题 CSS：

1. `themes/edg-one-page/source/css/layout/mimo-inspired.styl` 把 `.personal-hub-navbar` 强制设为不透明浅色背景和固定定位。
2. `astro-src/styles/calm-home.css` 把风景放在 92px 上边距、最大宽度 1560px 的独立圆角卡片里。
3. 实际风景视频选用的是有来源许可的实拍素材，而效果图里的雪山照片只是视觉合成示意，不能认定是同一画面。

此次优先使用仅针对 `.home-mimo-page` 的覆盖样式：把透明导航叠加到风景上，同时减少风景外的留白。后续改动应首先对照上述基准，不要让首页受到旧 Dashboard 规则影响。

## 验收方式

`npm run check` 只验证 Astro 和基础内容，不代表真实网页排版与效果图一致。验收至少包含：

- 桌面 1440×900：首页导航是否叠加在视频内部、风景是否近满屏、文本是否左对齐。
- 手机 390×844：导航语言菜单不重叠，标题可见且按钮已删除。
- 中文/英文首页及从首页切换到内页：内页仍保留原本的可读导航。
- 弱网时显示本地 WebP；降低动态效果时停播视频；方向键/触屏依然可切换。
