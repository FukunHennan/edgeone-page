## 冲突与采用依据

| 问题 | 本次处理 |
| --- | --- |
| 旧 `competition_flowchart.svg` 将暂停写成锁定控制，并提及视觉位置信息 | 不嵌入该旧图；按当前手册写暂停计时、录像继续、所属战队仍可操作 |
| `technical-architecture.svg` 暗示视觉运动指令 | 不据此宣称自动跟踪、识别或视觉导航；当前服务按相机和视频职责介绍 |
| 手册局部表格称 React 管理台为历史界面 | 依据 Vite 双入口、现有组件和手册后续章节，写赛事页与管理台并存 |
| 管理台保留 RGB 历史选项 | 不写成现有机器鱼功能，以硬件清单和固件能力为准 |
| 构建环境名为 XIAO，硬件清单写 Super Mini | 正文分别说明物理板型与构建环境名 |
| 仅将视频称为独立 WebRTC 链路不完整 | 主文与部署专题同步补充 TURN 和同源 WebSocket JPEG 降级 |
